# Smart Expense Tracker

A cross-platform personal finance app built with Expo + React Native + TypeScript and Supabase.

## Included
- Email/password sign-up, sign-in and sign-out
- Supabase cloud storage with per-user Row Level Security
- Realtime refresh for transactions and budgets across devices
- Income and expense transactions with categories, notes, dates and currency
- Multiple currencies (USD, BDT, EUR, GBP, INR, CAD, AUD, AED, SAR, JPY)
- Monthly category budgets with 80% and 100% local notification alerts
- Dashboard, transaction history, budget progress and spending reports
- English-only interface

## Requirements
- Node.js 20 or later
- Expo Go for quick device testing, or EAS Build for store-ready binaries
- A Supabase project

## 1. Install

```bash
npm install
```

## 2. Configure Supabase

1. Create a project at https://supabase.com/dashboard.
2. Open **SQL Editor** and run `supabase/schema.sql`.
3. In **Project Settings → API**, copy the Project URL and `anon` / publishable key.
4. Copy `.env.example` to `.env` and fill in the values:

```env
EXPO_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY
```

5. In Supabase **Authentication → Providers**, enable Email. Configure email confirmation as desired. Google sign-in can be enabled in Supabase after adding Google OAuth credentials; the UI currently implements email/password authentication.
6. Restart Expo after changing environment variables.

Never put a Supabase `service_role` key in a mobile app. Only use the anon/publishable key; RLS protects user data.

## 3. Run

```bash
npx expo start
```

Scan the QR code with Expo Go, or press `a` / `i` for an emulator. For iOS simulator use macOS. Web preview is available via `npm run web`, but native notifications are intended for Android/iOS.

## 4. Build Android and iOS

Install and configure EAS CLI:

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform all
```

Replace the example Android package and iOS bundle identifier in `app.json` with identifiers you own. Configure signing and store metadata in EAS / the Apple and Google developer consoles.

## Notes on currencies and totals

Each transaction and budget has its own ISO currency code. Dashboard totals and reports are deliberately filtered to the selected currency; the app does not add USD to BDT or other currencies without a conversion rate. This prevents misleading totals. An FX conversion feature can be added later with a trusted exchange-rate provider and a stored conversion snapshot per transaction.

## Budget notifications

The app requests notification permission on first launch. It checks category spending against the current month's budgets and sends alerts at 80% and 100%+. Notifications are local device notifications, so each signed-in device checks its own synced data. Push notifications while the app is closed would require Expo push tokens and a trusted server/Edge Function; do not expose server secrets in the app.

## Current limitations / next production steps

- Google OAuth button and password reset flow are not wired yet; email/password auth is implemented.
- Transactions are saved to Supabase; offline write queue is not implemented.
- Edit transaction, recurring transactions, CSV export, receipt scanning and FX conversion are future enhancements.
- Add app icon, splash artwork, privacy policy, support contact, legal disclosures and store screenshots before release.
- Add server-side scheduled budget checks if alerts must arrive while the app is closed.
